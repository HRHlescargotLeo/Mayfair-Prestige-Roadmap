## Mayfair Prestige roadmap prototypes

A clickable model of improvements to [mayfairprestigeuk.co.uk](https://www.mayfairprestigeuk.co.uk/): five big improvements and 29 quick wins.

- **Live:** https://hrhlescargotleo.github.io/Mayfair-Prestige-Roadmap/
- **Design:** lives entirely in `src/css/theme.css`; empty that file and the model returns to greyscale.
- **Photography:** `src/js/photos.js` loads Mayfair Prestige's own photos from mayfairprestigeuk.co.uk and applies each one only once it has loaded; anywhere they can't be reached, a drawn placeholder stays. Photography © Mayfair Prestige.

## Two tabs

**Big improvements** (`index.html`)

1. **The showroom online** – `pages/home.html`, `pages/inventory.html`
2. **Every car, properly presented** – `pages/car.html?car=<id>`
3. **Book a viewing, reserve with confidence** – `pages/viewing.html`, `pages/reserve.html`, `pages/contact.html`
4. **By invitation** – `pages/by-invitation.html`, `pages/sold.html`
5. **Private services** – `pages/services.html`, `pages/finance.html`

**Quick wins** (`quick-wins.html`): QW1 to QW29, one page each (`pages/qw-01.html` to `pages/qw-29.html`). These pages, the overview and `src/includes/qw-links.html` are generated by `tools/quick_wins.py`; edit the content there and rerun it. Their behaviour is in `src/js/quickwins.js`.

`modules/library.html` shows each new component once. Requirements (R01–R56 and QW1–QW29, mapped to the internal idea numbers) are in `requirements/requirements.md`.

## Data

`src/js/data.js` holds the 40 cars in stock and the 84 previously sold names from the live site (prices, mileages, derivatives, photo counts and image paths), captured 7 October 2026. Colour, interior, owners, status and days in stock are sample data. Finance figures use an illustrative 9.9% APR and are not quotes.

## Build

```
python3 tools/quick_wins.py && node build-includes.js && node validate.js
```

`build-includes.js` resolves `<!-- @@include -->` and `~/` paths from `src/` into `docs/`, and writes `docs/.nojekyll`. `validate.js` checks tag balance, inline handlers and internal links.
